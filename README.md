


# 🃏 Marcador de Truco

Um aplicativo simples e intuitivo desenvolvido em Flutter para contagem e gerenciamento de pontuações de partidas de Truco (Paulista e Mineiro).

## 🚀 Funcionalidades

- **Contagem de Pontos:** Adição e remoção rápida de pontos para a dupla/time ("Nós" vs "Eles").
- **Aumento de Aposta:** Botões de atalho para truco (3), seis (6), nove (9) e doze (12).
- **Limite de Vitória:** Alerta automático ao atingir a pontuação máxima da partida (12 pontos).
- **Reset Rápido:** Opção para reiniciar a partida ou zerar o placar com um único clique.
- **Interface Responsiva:** Layout adaptado para diferentes tamanhos de tela mobile.
